# 随身记 · SchedNautix

基于 **MyGo (`egoist/mygo`) + React / TypeScript** 构建的轻量化个人桌面随身记客户端。界面克制清晰、纯本地存储，回归个人日常记录与提醒本身。

## 核心功能

1. **每日任务 · 色块分区**
   - 按项目 / 议题创建柔和色块卡片（内置 8 套浅/深色适配配色），同一议题下的任务一目了然。
   - 支持按日切换（昨日 / 今日 / 明日 / 任意日期）、卡片内回车极速添加、`#Tag` 自动提取与筛选、以及「一键顺延昨日未完成任务」。
2. **随时记录（双入口）**
   - **主界面常驻「随手记」侧栏**：随时记录灵感与备忘，支持置顶、搜索、`#Tag` 归类，并可一键转为某日指定色块下的任务。
   - **全局悬浮速记框**：任何界面（含全屏应用上方）按 `Alt+Shift+Space`（可在设置中自定义）立即呼出无边框浮窗，支持「随手记」与「今日任务」一键切换，`Esc` 即收起。
3. **Tag 定时提醒 & 单任务提醒**
   - 可为任意 `#Tag` 配置周期或单次提醒（每天 / 工作日 / 自定义周几 / 单次日期 + `HH:MM`），后台常驻调度器到点弹出系统原生通知并自动汇总该 Tag 下的未完成事项。
   - 也支持给单条任务附加定点时间提醒；关闭主窗口自动退居系统托盘，确保提醒与全局快捷键持续生效。
4. **纯本地存储**
   - 数据以人类可读的 JSON 原子写入本地应用数据目录，支持一键在访达打开及导出 JSON 备份，零账号零云端负担。

## 本地运行与打包

```bash
# 开发模式（热更新 + 原生 .app 壳，可直接调试系统通知）
bun run dev

# 打包当前平台桌面客户端（输出到 build/darwin-arm64/ 等目录）
bun run build

# 运行 Go 后端单元测试 & 前端类型检查
bun run test:go
bun run typecheck
```
